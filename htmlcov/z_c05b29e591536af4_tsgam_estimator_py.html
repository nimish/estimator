211@dataclass 

212class TsgamOutlierConfig: 

213 """ 

214 Configuration for the outlier detector component. 

215 

216 The outlier detector identifies anomalous periods (e.g., days) in the time series 

217 with sparse multiplicative corrections. This component is particularly useful for 

218 detecting days with unusual patterns that deviate from the normal seasonal and 

219 trend behavior, such as holidays, special events, or data quality issues. 

220 

221 **How it works:** 

222 - The detector assigns one correction value per period (e.g., per day) 

223 - Corrections are constant across all samples within a period 

224 - L1 regularization encourages sparsity: most periods have no correction (≈0), 

225 while only outlier periods have non-zero corrections 

226 - The correction is additive in log space, which translates to a multiplicative 

227 effect in the original scale (e.g., 0.2 in log space ≈ 0.82x multiplier, 

228 0.5 in log space ≈ 1.65x multiplier) 

229 

230 **Mathematical formulation:** 

231 The outlier term is added to the model as: ``T @ outlier``, where: 

232 - ``T`` is a binary matrix mapping each sample to its period 

233 - ``outlier`` is a sparse vector of period-level corrections 

234 - The L1 penalty ``reg_weight * ||outlier||_1`` encourages sparsity 

235 

236 Parameters 

237 ---------- 

238 reg_weight : float 

239 L1 regularization weight controlling sparsity of outlier detection. 

240 Higher values encourage more sparsity (fewer outliers detected). 

241 Lower values allow more outliers to be detected. 

242 

243 **Typical ranges:** 

244 - Very sparse (few outliers): 0.01 to 0.1 

245 - Moderate sparsity: 0.001 to 0.01 

246 - More sensitive (more outliers): 0.0001 to 0.001 

247 

248 **Guidelines:** 

249 - Start with 0.002 and adjust based on results 

250 - If too many outliers detected (>10% of periods), increase reg_weight 

251 - If no outliers detected, decrease reg_weight 

252 - For real-world data, values between 0.001 and 0.01 are often appropriate 

253 

254 period_hours : float or None, default=None 

255 Period length in hours for which the outlier correction is constant. 

256 If None, defaults to 24.0 hours (daily outliers) for hourly data. 

257 

258 **Examples:** 

259 - Hourly data, daily outliers: ``period_hours=24.0`` (default) 

260 - 15-minute data, daily outliers: ``period_hours=24.0`` (96 samples per day) 

261 - Hourly data, weekly outliers: ``period_hours=168.0`` (7 days) 

262 - Daily data, weekly outliers: ``period_hours=7.0`` 

263 - Hourly data, hourly outliers: ``period_hours=1.0`` (not recommended, use AR instead) 

264 

265 Attributes 

266 ---------- 

267 reg_weight : float 

268 L1 regularization weight. 

269 period_hours : float or None 

270 Period length in hours. 

271 

272 Notes 

273 ----- 

274 - The outlier detector works best when the target is log-transformed, as it 

275 naturally models multiplicative effects 

276 - Outlier corrections are applied during both fit and predict 

277 - For prediction periods beyond the training data, outlier corrections default 

278 to 0 (no correction) 

279 - The detector is most effective when combined with other components (seasonality, 

280 trend, exogenous variables) that explain normal variation, leaving outliers 

281 as the residual anomaly 

282 

283 Examples 

284 -------- 

285 >>> # Daily outlier detector for hourly data (default, moderate sparsity) 

286 >>> config = TsgamOutlierConfig(reg_weight=0.002) 

287 >>> 

288 >>> # Weekly outlier detector with higher sparsity (fewer outliers) 

289 >>> config = TsgamOutlierConfig(reg_weight=0.01, period_hours=168.0) 

290 >>> 

291 >>> # Daily outlier detector with lower sparsity (more outliers detected) 

292 >>> config = TsgamOutlierConfig(reg_weight=0.001) 

293 >>> 

294 >>> # Very sparse detector (only extreme outliers) 

295 >>> config = TsgamOutlierConfig(reg_weight=0.1) 

296 >>> 

297 >>> # Use in full estimator configuration 

298 >>> from tsgam_estimator import TsgamEstimatorConfig 

299 >>> estimator_config = TsgamEstimatorConfig( 

300 ... outlier_config=TsgamOutlierConfig(reg_weight=0.002) 

301 ... ) 

302 """ 

303 reg_weight: float 

304 period_hours: float | None = None

419def get_recommended_periods(X: pd.DataFrame, include_harmonics: bool = False) -> list[float] | tuple[list[float], list[int]]: 

420 """ 

421 Get recommended periods for Fourier basis based on data frequency. 

422 

423 This function infers the frequency of the input time series data and returns 

424 recommended periods (in hours) that are appropriate for capturing seasonal 

425 patterns at that time scale. Periods are calculated as multiples of the 

426 data's base frequency, then converted to hours. 

427 

428 Parameters 

429 ---------- 

430 X : pd.DataFrame 

431 Input data with DatetimeIndex or first column containing datetime values. 

432 include_harmonics : bool, default=False 

433 If True, also returns recommended number of harmonics for each period. 

434 

435 Returns 

436 ------- 

437 periods : list[float] 

438 Recommended periods in hours. Periods are calculated as multiples of the 

439 data's base frequency, then converted to hours. For example: 

440 - For 5-minute data: multiples [1, 3, 12, 288, 2016] of 5-minute intervals 

441 - For hourly data: multiples [24, 168, 8765.82] of 1-hour intervals 

442 - For daily data: multiples [7, 365.2425] of 1-day intervals 

443 

444 The periods capture: 

445 - Short-term patterns (small multiples: 1x, 3x, 5x, etc.) 

446 - Daily patterns (multiples corresponding to ~24 hours) 

447 - Weekly patterns (multiples corresponding to ~168 hours) 

448 - Yearly patterns (multiples corresponding to ~8766 hours) when appropriate 

449 num_harmonics : list[int], optional 

450 Recommended number of harmonics for each period. Only returned if 

451 include_harmonics=True. Higher harmonics capture more complex patterns. 

452 

453 Examples 

454 -------- 

455 >>> import pandas as pd 

456 >>> import numpy as np 

457 >>> from tsgam_estimator import get_recommended_periods 

458 >>> 

459 >>> # For 1-minute data: periods are multiples of 1-minute intervals 

460 >>> dates = pd.date_range('2020-01-01', periods=1000, freq='1min') 

461 >>> X = pd.DataFrame({'value': np.random.randn(1000)}, index=dates) 

462 >>> periods = get_recommended_periods(X) 

463 >>> # Returns periods like [1/60, 5/60, 15/60, 1, 24, 168] (hours) 

464 >>> # These correspond to 1, 5, 15, 60, 1440, 10080 minutes 

465 >>> 

466 >>> # For 5-minute data: periods are multiples of 5-minute intervals 

467 >>> dates = pd.date_range('2020-01-01', periods=1000, freq='5min') 

468 >>> X = pd.DataFrame({'value': np.random.randn(1000)}, index=dates) 

469 >>> periods = get_recommended_periods(X) 

470 >>> # Returns periods like [5/60, 15/60, 1, 24, 168] (hours) 

471 >>> # These correspond to 1, 3, 12, 288, 2016 five-minute intervals 

472 >>> 

473 >>> # For hourly data: periods are multiples of 1-hour intervals 

474 >>> dates = pd.date_range('2020-01-01', periods=1000, freq='h') 

475 >>> X = pd.DataFrame({'value': np.random.randn(1000)}, index=dates) 

476 >>> periods, harmonics = get_recommended_periods(X, include_harmonics=True) 

477 >>> # Returns periods like [24, 168, 8766] (hours) 

478 >>> # These correspond to 24, 168, 8766 hourly intervals 

479 """ 

480 # Extract timestamps 

481 if isinstance(X, pd.DataFrame): 

482 if isinstance(X.index, pd.DatetimeIndex): 

483 timestamps = X.index 

484 elif len(X.columns) > 0 and pd.api.types.is_datetime64_any_dtype(X.iloc[:, 0]): 

485 timestamps = pd.DatetimeIndex(X.iloc[:, 0]) 

486 else: 

487 raise ValueError( 

488 "X must have DatetimeIndex or first column must be datetime. " 

489 "Got DataFrame without datetime index or datetime column." 

490 ) 

491 else: 

492 raise ValueError( 

493 "X must be a pandas DataFrame with DatetimeIndex or datetime column. " 

494 f"Got {type(X)} instead." 

495 ) 

496 

497 if len(timestamps) < 2: 

498 raise ValueError("Need at least 2 timestamps to infer frequency.") 

499 

500 # Infer frequency and calculate base time step 

501 inferred_freq = pd.infer_freq(timestamps) 

502 if inferred_freq is None: 

503 # Try to infer from differences 

504 diffs = timestamps[1:] - timestamps[:-1] 

505 median_diff = diffs.median() 

506 base_step_hours = median_diff.total_seconds() / 3600.0 

507 # Convert to approximate frequency string 

508 if median_diff <= pd.Timedelta(minutes=1): 

509 inferred_freq = '1min' 

510 elif median_diff <= pd.Timedelta(minutes=5): 

511 inferred_freq = '5min' 

512 elif median_diff <= pd.Timedelta(minutes=15): 

513 inferred_freq = '15min' 

514 elif median_diff <= pd.Timedelta(hours=1): 

515 inferred_freq = 'h' 

516 base_step_hours = 1.0 

517 elif median_diff <= pd.Timedelta(days=1): 

518 inferred_freq = 'D' 

519 base_step_hours = 24.0 

520 else: 

521 raise ValueError( 

522 "Could not infer frequency from timestamps. " 

523 "Timestamps must be regularly spaced." 

524 ) 

525 else: 

526 # Calculate base step from frequency string using pd.to_timedelta 

527 try: 

528 freq_td_str = inferred_freq if inferred_freq[0].isdigit() else f'1{inferred_freq}' 

529 base_step_hours = pd.to_timedelta(freq_td_str).total_seconds() / 3600.0 

530 except (ValueError, IndexError): 

531 diffs = timestamps[1:] - timestamps[:-1] 

532 base_step_hours = diffs.median().total_seconds() / 3600.0 

533 

534 # Determine periods as multiples of base frequency, then convert to hours. 

535 # Use base_step_hours ranges to select appropriate period multiples, 

536 # independent of the particular frequency string format pandas returns. 

537 periods = [] 

538 num_harmonics = [] 

539 

540 if base_step_hours < 1 / 60: # Sub-minute frequency 

541 period_multiples = [1, 5, 15, 60, 1440, 10080] 

542 num_harmonics = [4, 3, 3, 6, 4, 3] 

543 periods = [mult * base_step_hours for mult in period_multiples] 

544 elif base_step_hours < 1: # Sub-hourly (minute-level) frequency 

545 minutes = round(base_step_hours * 60) 

546 if minutes == 1: 

547 period_multiples = [1, 5, 15, 60, 1440, 10080] 

548 num_harmonics = [4, 3, 3, 6, 4, 3] 

549 elif minutes == 5: 

550 period_multiples = [1, 3, 12, 288, 2016] 

551 num_harmonics = [3, 3, 6, 4, 3] 

552 elif minutes == 15: 

553 period_multiples = [1, 4, 96, 672] 

554 num_harmonics = [3, 6, 4, 3] 

555 else: 

556 periods_per_day = (24 * 60) / minutes 

557 periods_per_week = (7 * 24 * 60) / minutes 

558 period_multiples = [1, 3, int(periods_per_day / 24), int(periods_per_day), int(periods_per_week)] 

559 num_harmonics = [3, 3, 6, 4, 3] 

560 periods = [mult * base_step_hours for mult in period_multiples] 

561 elif abs(base_step_hours - 1.0) < 0.01: # Hourly 

562 period_multiples = [24, 168, PERIOD_HOURLY_YEARLY] 

563 num_harmonics = [6, 4, 3] 

564 periods = [mult * base_step_hours for mult in period_multiples] 

565 elif abs(base_step_hours - 24.0) < 0.01: # Daily 

566 period_multiples = [7, PERIOD_DAILY_YEARLY] 

567 num_harmonics = [4, 3] 

568 periods = [mult * base_step_hours for mult in period_multiples] 

569 elif abs(base_step_hours - 168.0) < 0.5: # Weekly 

570 period_multiples = [PERIOD_WEEKLY_YEARLY] 

571 num_harmonics = [3] 

572 periods = [mult * base_step_hours for mult in period_multiples] 

573 else: 

574 # Unknown frequency - provide generic recommendations 

575 # Try to estimate from median time difference 

576 diffs = timestamps[1:] - timestamps[:-1] 

577 median_diff_hours = diffs.median().total_seconds() / 3600.0 

578 

579 if median_diff_hours < 1/60: # Sub-minute frequency 

580 # Use multiples appropriate for minute-level data 

581 period_multiples = [1, 5, 15, 60, 1440, 10080] 

582 num_harmonics = [4, 3, 3, 6, 4, 3] 

583 periods = [mult * base_step_hours for mult in period_multiples] 

584 elif median_diff_hours < 1: # Sub-hourly frequency 

585 # Calculate multiples for daily and weekly patterns 

586 periods_per_day = 24.0 / base_step_hours 

587 periods_per_week = 168.0 / base_step_hours 

588 period_multiples = [int(periods_per_day), int(periods_per_week)] 

589 num_harmonics = [6, 4, 3] 

590 periods = [mult * base_step_hours for mult in period_multiples] 

591 elif median_diff_hours < 24: # Sub-daily frequency 

592 # Calculate multiples for daily, weekly, and yearly patterns 

593 periods_per_day = 24.0 / base_step_hours 

594 periods_per_week = 168.0 / base_step_hours 

595 periods_per_year = 365.2425 * 24.0 / base_step_hours 

596 period_multiples = [int(periods_per_day), int(periods_per_week), int(periods_per_year)] 

597 num_harmonics = [6, 4, 3] 

598 periods = [mult * base_step_hours for mult in period_multiples] 

599 else: # Daily or longer frequency 

600 # Calculate multiples for weekly and yearly patterns 

601 periods_per_week = 7.0 / (base_step_hours / 24.0) 

602 periods_per_year = 365.2425 / (base_step_hours / 24.0) 

603 period_multiples = [int(periods_per_week), int(periods_per_year)] 

604 num_harmonics = [4, 3] 

605 periods = [mult * base_step_hours for mult in period_multiples] 

606 

607 if include_harmonics: 

608 return periods, num_harmonics 

609 else: 

610 return periods

837 def _infer_frequency_from_differences(self, timestamps: pd.DatetimeIndex) -> str: 

838 """ 

839 Infer the intended frequency from time differences, even when there are gaps. 

840 

841 This method finds the most common time difference between consecutive timestamps 

842 and maps it to a pandas frequency string. 

843 

844 Parameters 

845 ---------- 

846 timestamps : DatetimeIndex 

847 Timestamps (may have gaps) 

848 

849 Returns 

850 ------- 

851 freq : str 

852 Inferred frequency string (e.g., 'h', '15min', 'D') 

853 """ 

854 if len(timestamps) < 2: 

855 raise ValueError("Need at least 2 timestamps to infer frequency") 

856 

857 # Compute time differences 

858 diffs = timestamps[1:] - timestamps[:-1] 

859 diff_seconds = np.array([d.total_seconds() for d in diffs]) 

860 

861 # Find the most common difference (mode) 

862 # Use histogram to find the most frequent difference 

863 # Round to nearest second to handle floating point issues 

864 diff_seconds_rounded = np.round(diff_seconds).astype(int) 

865 unique_diffs, counts = np.unique(diff_seconds_rounded, return_counts=True) 

866 most_common_diff_seconds = unique_diffs[np.argmax(counts)] 

867 

868 # Map to pandas frequency string 

869 # Common mappings: 

870 freq_mapping = { 

871 60: '1min', 

872 300: '5min', 

873 900: '15min', 

874 3600: '1h', 

875 86400: '1D', 

876 } 

877 

878 # Try exact match first 

879 if most_common_diff_seconds in freq_mapping: 

880 return freq_mapping[most_common_diff_seconds] 

881 

882 # Try approximate match (within 1% tolerance) 

883 for diff_sec, freq_str in freq_mapping.items(): 

884 if abs(most_common_diff_seconds - diff_sec) / diff_sec < 0.01: 

885 return freq_str 

886 

887 # If no match, try to construct frequency from seconds 

888 if most_common_diff_seconds < 60: 

889 return f'{most_common_diff_seconds}S' 

890 elif most_common_diff_seconds < 3600: 

891 minutes = most_common_diff_seconds // 60 

892 return f'{minutes}min' 

893 elif most_common_diff_seconds < 86400: 

894 hours = most_common_diff_seconds // 3600 

895 return f'{hours}h' 

896 else: 

897 days = most_common_diff_seconds // 86400 

898 return f'{days}D'

1034 def _make_regularization_matrix(self, num_harmonics: list[int], 

1035 weight: float, 

1036 periods: list[float], 

1037 drop_constant: bool = False, 

1038 standing_wave: bool | list[bool] = False, 

1039 trend: bool = False, 

1040 max_cross_k: int | None = None, 

1041 custom_basis: dict[int, ndarray] | None = None) -> spmatrix: 

1042 """ 

1043 Create regularization matrix for Fourier coefficients. 

1044 

1045 Parameters 

1046 ---------- 

1047 num_harmonics : int or array-like 

1048 Number of harmonics for each period. 

1049 weight : float 

1050 Regularization weight. 

1051 periods : float or array-like 

1052 Periods for each harmonic block. 

1053 standing_wave : bool or array-like, default=False 

1054 Whether to use standing wave basis. 

1055 trend : bool, default=False 

1056 Whether to include trend term. 

1057 max_cross_k : int or None, default=None 

1058 Maximum cross terms. 

1059 custom_basis : dict or None, default=None 

1060 Custom basis matrices. 

1061 

1062 Returns 

1063 ------- 

1064 D : sparse matrix 

1065 Regularization matrix. 

1066 """ 

1067 sort_idx, Ps, num_harmonics, standing_wave = initialize_arrays( 

1068 num_harmonics, periods, standing_wave, custom_basis 

1069 ) 

1070 ls_original = [weight * (2 * np.pi) / np.sqrt(P) for P in Ps] 

1071 

1072 # Create sequence of values from 1 to K 

1073 i_value_list = [] 

1074 for ix, nh in enumerate(num_harmonics): 

1075 if standing_wave[ix]: 

1076 i_value_list.append(np.arange(1, nh + 1)) 

1077 else: 

1078 i_value_list.append(np.repeat(np.arange(1, nh + 1), 2)) 

1079 

1080 # Create blocks of coefficients 

1081 blocks_original = [iv * lx for iv, lx in zip(i_value_list, ls_original)] 

1082 if custom_basis is not None: 

1083 for ix, val in custom_basis.items(): 

1084 ixt = np.where(sort_idx == ix)[0][0] 

1085 blocks_original[ixt] = ls_original[ixt] * np.arange(1, val.shape[1] + 1) 

1086 

1087 if max_cross_k is not None: 

1088 max_cross_k *= 2 

1089 

1090 # Compute cross-term penalties 

1091 blocks_cross = [ 

1092 [l2 for l1 in c[0][:max_cross_k] for l2 in c[1][:max_cross_k]] 

1093 for c in combinations(blocks_original, 2) 

1094 ] 

1095 

1096 # Combine blocks 

1097 if trend is False: 

1098 first_block = [np.zeros(1)] 

1099 else: 

1100 first_block = [np.zeros(2)] 

1101 

1102 if drop_constant: 

1103 first_block = first_block[1:] 

1104 

1105 coeff_i = np.concatenate(first_block + blocks_original + blocks_cross) 

1106 

1107 D = spdiags(coeff_i, 0, coeff_i.size, coeff_i.size) 

1108 return D

1112 def _make_H(self, x: ndarray, knots: ndarray, include_offset: bool = False) -> ndarray: 

1113 """ 

1114 Create cubic spline basis matrix. 

1115 

1116 Parameters 

1117 ---------- 

1118 x : array-like 

1119 Input values. 

1120 knots : array-like 

1121 Knot locations. 

1122 include_offset : bool, default=False 

1123 Whether to include constant term. 

1124 

1125 Returns 

1126 ------- 

1127 H : ndarray 

1128 Basis matrix. 

1129 """ 

1130 def d_func(x, k, k_max): 

1131 n1 = np.clip(np.power(x - k, 3), 0, np.inf) 

1132 n2 = np.clip(np.power(x - k_max, 3), 0, np.inf) 

1133 d1 = k_max - k 

1134 out = (n1 - n2) / d1 

1135 return out 

1136 

1137 nK = len(knots) 

1138 H = np.ones((len(x), nK), dtype=float) 

1139 H[:, 1] = x 

1140 for _i in range(nK - 2): 

1141 _j = _i + 2 

1142 H[:, _j] = d_func(x, knots[_i], knots[-1]) - d_func( 

1143 x, knots[-2], knots[-1] 

1144 ) 

1145 if include_offset: 

1146 return H 

1147 else: 

1148 return H[:, 1:]

1150 def _make_offset_H(self, H: ndarray, offset: int) -> ndarray: 

1151 """ 

1152 Create lead/lag version of basis matrix. 

1153 

1154 Parameters 

1155 ---------- 

1156 H : ndarray 

1157 Original basis matrix. 

1158 offset : int 

1159 Lead/lag offset (positive = lag, negative = lead). 

1160 

1161 Returns

1163 newH : ndarray 

1164 Offset basis matrix with NaN padding. 

1165 """

1167 if offset > 0: 

1168 newH[-offset:] = np.nan 

1169 elif offset < 0: 

1170 newH[:-offset] = np.nan 

1171 return newH

1284 def _get_min_samples_required(self) -> int: 

1285 """ 

1286 Calculate minimum number of samples required based on lags. 

1287 

1288 For positive lags (looking back), we need at least that many samples. 

1289 For negative lags (leads/looking forward), we need at least abs(lag) samples. 

1290 For AR lags, we need at least max(ar_lags) samples. 

1291 

1292 Returns 

1293 ------- 

1294 min_samples : int 

1295 Minimum number of samples required. 

1296 """ 

1297 all_exog_lags = [] 

1298 for exog_cfg in self.config.exog_config or []: 

1299 all_exog_lags.extend(exog_cfg.lags) 

1300 

1301 max_positive_lag = 0 

1302 min_negative_lag = 0 

1303 for lag in all_exog_lags: 

1304 if lag > 0: 

1305 max_positive_lag = max(max_positive_lag, lag) 

1306 elif lag < 0: 

1307 min_negative_lag = min(min_negative_lag, lag) 

1308 max_negative_lag = abs(min_negative_lag) 

1309 

1310 # AR lags are typically positive (looking back) 

1311 max_ar_lag = 0 

1312 if self.config.ar_config is not None: 

1313 max_ar_lag = max(self.config.ar_config.lags) if self.config.ar_config.lags else 0 

1314 

1315 # Need enough samples for the maximum backward-looking lag (exog or AR) 

1316 # plus enough samples for the maximum forward-looking lag 

1317 # plus 1 for at least one valid sample where all requirements overlap 

1318 min_samples = max(max_positive_lag, max_ar_lag) + max_negative_lag + 1 

1319 

1320 return min_samples

1332

1593 def _fit_ar_model(self, X_array: ndarray, y: ndarray, time_indices: ndarray) -> None: 

1594 """ 

1595 Fit AR model on baseline residuals. 

1596 

1597 Parameters 

1598 ---------- 

1599 X_array : ndarray 

1600 Exogenous variables array. 

1601 y : ndarray 

1602 Target values. 

1603 time_indices : ndarray 

1604 Time indices for Fourier basis. 

1605 """ 

1606 # Get baseline predictions 

1607 baseline_pred = np.full(len(y), self.variables_['constant'].value) 

1608 

1609 # Add exogenous terms if present 

1610 if self.config.exog_config: 

1611 for ix, exog_cfg in enumerate(self.config.exog_config): 

1612 exog_var = X_array[:, ix] 

1613 stored_knots = self.exog_knots_[ix] if isinstance(exog_cfg, TsgamSplineConfig) else None 

1614 _, Hs = self._process_exog_config(exog_cfg, exog_var, knots=stored_knots) 

1615 exog_coef = self.variables_[f'exog_coef_{ix}'].value 

1616 if exog_coef is not None: 

1617 exog_pred = np.sum([H @ exog_coef[:, lag_ix] for lag_ix, H in enumerate(Hs)], axis=0) 

1618 baseline_pred += exog_pred 

1619 

1620 # Add Fourier terms if present 

1621 if self.config.multi_periodic_config: 

1622 max_idx = int(np.max(time_indices)) 

1623 F_full = make_basis_matrix( 

1624 num_harmonics=self.config.multi_periodic_config.num_harmonics, 

1625 length=max_idx + 1, 

1626 periods=self.config.multi_periodic_config.periods 

1627 ) 

1628 F = F_full[time_indices.astype(int), 1:] # Drop constant column 

1629 fourier_coef = self.variables_['fourier_coef'].value 

1630 if fourier_coef is not None: 

1631 baseline_pred += F @ fourier_coef 

1632 

1633 # Add trend term if present 

1634 if self.config.trend_config is not None and self.config.trend_config.trend_type != TrendType.NONE and 'trend' in self.variables_: 

1635 trend = self.variables_['trend'].value 

1636 if trend is not None and hasattr(self, 'trend_T_matrix_'): 

1637 T = self.trend_T_matrix_ 

1638 baseline_pred += T @ trend 

1639 

1640 # Compute residuals on valid samples 

1641 residuals = y[self.combined_valid_mask_] - baseline_pred[self.combined_valid_mask_] 

1642 

1643 # Build AR design matrix 

1644 if self.config.ar_config is None: 

1645 return 

1646 ar_config = self.config.ar_config 

1647 ar_lags = len(ar_config.lags) 

1648 B = self._running_view(residuals, ar_lags) 

1649 ar_valid_mask = np.all(~np.isnan(B), axis=1) 

1650 

1651 if self.config.debug: 

1652 self._B_running_view_ = B 

1653 self._ar_valid_mask_ = ar_valid_mask 

1654 self._baseline_residuals_ = residuals 

1655

1658 self.ar_coef_ = None 

1659 self.ar_intercept_ = None 

1660 self.ar_noise_loc_ = None 

1661 self.ar_noise_scale_ = None 

1662 return 

1663

1665 theta = cvxpy.Variable(ar_lags) 

1666 constant = cvxpy.Variable() 

1667 

1668 ar_problem = cvxpy.Problem( 

1669 cvxpy.Minimize(cvxpy.sum_squares(residuals[ar_valid_mask] - B[ar_valid_mask] @ theta - constant)), 

1670 [cvxpy.norm1(theta) <= ar_config.l1_constraint] 

1671 ) 

1672 ar_problem.solve(solver=self.config.solver_config.solver, verbose=self.config.solver_config.verbose) 

1673 

1674 if ar_problem.status not in ["infeasible", "unbounded"]: 

1675 assert theta.value is not None, "AR coefficients should be set" 

1676 assert constant.value is not None, "AR intercept should be set" 

1677 self.ar_coef_ = theta.value 

1678 self.ar_intercept_ = constant.value

1681 ar_model = B[ar_valid_mask] @ theta.value + constant.value 

1682 ar_residuals = residuals[ar_valid_mask] - ar_model 

1683 self.ar_noise_loc_, self.ar_noise_scale_ = stats.laplace.fit(ar_residuals) 

1684 else: 

1685 # AR model failed to solve 

1686 self.ar_coef_ = None 

1687 self.ar_intercept_ = None 

1688 self.ar_noise_loc_ = None 

1689 self.ar_noise_scale_ = None

1691 def predict(self, X: pd.DataFrame, 

1692 remove_periodic : bool = False, remove_exogenous : bool = False, 

1693 remove_trend : bool = False) -> ndarray: 

1694 """

1994 def _generate_ar_samples(self, baseline_pred: ndarray, n_samples: int, random_state: RandomState) -> ndarray: 

1995 """ 

1996 Generate samples with AR noise rollout using residuals. 

1997 

1998 Parameters 

1999 ---------- 

2000 baseline_pred : ndarray 

2001 Baseline predictions (same scale as training data). 

2002 n_samples : int 

2003 Number of samples to generate. 

2004 random_state : RandomState 

2005 Random state for reproducible results. 

2006 

2007 Returns 

2008 ------- 

2009 samples : ndarray of shape (n_samples, len(baseline_pred)) 

2010 Sample predictions with AR noise (same scale as training data). 

2011 """ 

2012 assert self.ar_coef_ is not None and self.ar_intercept_ is not None, \ 

2013 "AR coefficients must be set before generating samples" 

2014 assert self.ar_noise_loc_ is not None and self.ar_noise_scale_ is not None, \ 

2015 "AR noise distribution parameters must be set before generating samples" 

2016 

2017 if random_state is not None: 

2018 if isinstance(random_state, np.random.RandomState): 

2019 rng = random_state 

2020 else: 

2021 rng = np.random.RandomState(random_state) 

2022 else: 

2023 rng = np.random.RandomState() 

2024 

2025 ar_coef = self.ar_coef_ 

2026 ar_intercept = self.ar_intercept_ 

2027 ar_noise_loc = self.ar_noise_loc_ 

2028 ar_noise_scale = self.ar_noise_scale_ 

2029 ar_lags = len(ar_coef) 

2030 length = len(baseline_pred) 

2031 nvals = length + ar_lags * 2 

2032 samples = np.zeros((n_samples, len(baseline_pred))) 

2033 # Prepare filter coefficients 

2034 a = np.concatenate([[1], -ar_coef[::-1]]) 

2035 b = np.array([1]) 

2036 for i in range(n_samples): 

2037 # Generate i.i.d. noise for the entire sequence 

2038 noise = stats.laplace.rvs( 

2039 loc=ar_noise_loc, 

2040 scale=ar_noise_scale, 

2041 size=nvals, 

2042 random_state=rng 

2043 ) 

2044 

2045 # Input to the filter 

2046 x = ar_intercept + noise 

2047 

2048 # Initialize the filter state with the first ar_lags noise values 

2049 # This matches the original "window" initialization 

2050 initial_window = noise[:ar_lags] 

2051 

2052 # Convert initial window to filter initial conditions 

2053 # For an AR process, we need to set zi such that the first outputs match our window 

2054 if ar_lags > 0: 

2055 zi = np.zeros(ar_lags) 

2056 # Work backwards through the initial window to set up the state 

2057 for j in range(ar_lags): 

2058 zi[j] = initial_window[ar_lags - 1 - j] 

2059 else: 

2060 zi = None 

2061 

2062 # Apply the AR filter starting after the initial window 

2063 if zi is not None: 

2064 ar_noise, _ = signal.lfilter(b, a, x[ar_lags:], zi=zi) 

2065 # Prepend the initial window 

2066 ar_noise = np.concatenate([initial_window, ar_noise]) 

2067 else: 

2068 ar_noise, _ = signal.lfilter(b, a, x) 

2069 

2070 # Use last length values (after burn-in) 

2071 ar_noise = ar_noise[-length:] 

2072 samples[i] = baseline_pred + ar_noise 

2073 return samples
